# Product Roadmap

This roadmap describes product outcomes rather than commit-count targets. Scope
will be implemented and pushed in reviewable increments as development happens.

## Foundation

- [x] Create and validate a multi-drill training session.
- [x] Define stable, versioned records for private local storage.
- [x] Save and restore a training plan through an atomic local-file adapter.
- Add a command-line workflow for planning and completing a session.

## Training journal

- Record completed drills, perceived effort, and private notes.
- Compare planned time with completed time.
- Filter the journal by date, focus, and intensity.

## Goals and workload

- Create measurable development goals with target dates.
- Connect completed sessions to relevant goals.
- Review weekly workload without making medical or injury claims.

## Personal review

- Produce deterministic weekly and monthly summaries.
- Export and restore a versioned private backup.
- Add an accessible local web interface after domain contracts stabilize.

Features will be revised when real use reveals better priorities. Empty modules,
placeholder features, and generated line-count padding are explicitly out of
scope.
